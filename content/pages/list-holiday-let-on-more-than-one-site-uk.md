Many UK hosts list the same home on more than one site. You keep the listing you already have and add one or two more, so more guests can find you. The one thing that has to be right is the calendar. We run Book Homes, one of the sites you could add, so we are not neutral, but the steps below work for any combination.

## Step 1: get your first listing in order

Before you add a site, make sure your current listing is accurate: photos, beds, house rules, check-in times and cancellation policy. You will copy most of it to the next site. Write it in your own words, and only copy text and photos that you own.

## Step 2: add the new site

Create the listing on the new site. Some sites can import from another: Book Homes, for example, can copy an Airbnb listing from its link (never reviews, ratings or prices). Others need you to fill it in by hand.

Keep the facts the same everywhere: the number of guests, beds and bathrooms, and the rules. Guests compare.

## Step 3: connect the calendars both ways

Each site gives you an **export** link (an iCal link that usually ends in .ics) and a place to **import** other sites' links.

1. Copy the export link from site A and import it into site B.
2. Copy the export link from site B and import it into site A.
3. Repeat for every pair, or import every site into each of the others.

| Site | How often it reads imported calendars |
|---|---|
| Airbnb | About every 3 hours, or when you press Refresh |
| Vrbo | Imported events can take up to 20 minutes to show (dashboard) |
| Booking.com | On its own schedule, often a few hours |
| Book Homes | Every 15 minutes |

## Step 4: set prices and rules on each site

iCal only shares booked and blocked dates. It does not share prices, minimum stays or messages. Set those on each site. Fees differ by site, so many hosts set a slightly different nightly rate per site to end up with a similar payout.

## Step 5: keep one record of nights let

Keep your own list of nights let across all sites. You need it for tax, for local rules such as London's 90-night limit, and probably for the national short-let register expected in England from March 2027.

## When to use a channel manager

If you run several homes or more than three sites, a channel manager (such as Guesty, Hostaway, Lodgify or Smoobu) can hold your calendar and prices in one place and push them out. Connect each site to the channel manager, not to each other, so every date comes from one source.
