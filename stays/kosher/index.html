Questions

Are these homes kosher certified?

No. Kosher details on Book Homes are provided by each host and describe the kitchen and home as the host keeps it. Book Homes does not inspect or certify kashrut. If you need a particular standard, ask the host after booking or check with your rabbi.

What does Shabbat friendly mean here?

The host says the home has a non-electric key or keypad override, no motion-sensor lights (or they can be switched off) and things like a Shabbat hot plate, urn or timers. Each listing shows exactly what the host declared.

How do I find homes near a shul?

Use the Near shul filter. It shows homes where the host says the nearest shul is a 15-minute walk or less, with the shul name on the listing.

Is there an eruv?

Each listing shows what the host told us: inside an eruv, not inside, or not sure. Please check the current eruv status locally before Shabbat.

Are there booking fees?

No. The price you see is the total for the stay, including cleaning. There is no guest service fee.
